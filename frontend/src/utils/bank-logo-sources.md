# Bank symbol sources

- Nubank: [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/nubank.svg), distributed under CC0. The original 24×24 path is translated into the existing purple bank avatar.
- C6 Bank: [Wikimedia Commons — Logo C6 Bank.svg](https://commons.wikimedia.org/wiki/File:Logo_C6_Bank.svg), attributed to C6 Bank and marked public domain (PD-textlogo). The C6 symbol subpaths of the vector wordmark are scaled uniformly into the existing dark bank avatar.

These vectors are bundled with the app, without runtime requests to external logo services. Custom account and card images remain user-selected assets.
